# Picture Round — image credits

These forty come from the Metropolitan Museum's open-access API, from the Art
Institute of Chicago's open-access collection and from NASA's image library
rather than from Commons, so the `Commons template` column records the Commons
template that names the same basis: `CC0` for a Met object whose record says
`isPublicDomain=true` and for an Art Institute work whose record says
`is_public_domain=true` and whose object page states "CC0 Public Domain
Designation", `PD-NASA` for a NASA image released under the agency's media usage
guidelines. The licence was checked on the **object record**, not on the
collection: an open-access collection can still contain items that are not free,
and two candidates were dropped for exactly that reason while this pack was
assembled. The first seventeen images came with the original pack, the other twenty-three
when the packs grew to forty questions; candidates were also dropped then for
visible text that gives the answer away, for a negative-looking scan, and
because an enhanced-colour Jupiter image carries a citizen-scientist processing
credit whose licence is not public domain.

The policy the column is checked against is in
[`../LICENSING.md`](../LICENSING.md), and
`tests/test_pack_image_licences_795.py` enforces it row by row.
