Setup

Installed in three steps

  1. Add via HACS. Open the HACS repository link, install Quizify, and restart Home Assistant.
  2. Add the integration. Settings → Devices & Services → Add Integration → Quizify.
  3. Open Quizify. It appears in your sidebar. Hit Quizify öffnen, pick a pack, and start the game — guests scan the QR code to join.
